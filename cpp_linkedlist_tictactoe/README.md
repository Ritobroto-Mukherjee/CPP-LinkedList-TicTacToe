# Linked List and Tic-Tac-Toe (C++ / CMake)

A small C++ project that separates the linked-list and tic-tac-toe implementations into header/source pairs and links them into one executable.

## Project structure

```text
cpp_linkedlist_tictactoe/
├── CMakeLists.txt
├── README.md
├── main.cpp
├── include/
│   ├── LinkedList.h
│   └── TicTacToe.h
└── src/
    ├── LinkedList.cpp
    └── TicTacToe.cpp
```

## Build out of source

From this directory:

```bash
cmake -S . -B build
cmake --build build
```

Run the executable:

- Linux / WSL: `./build/linkedlist_tictactoe`
- Windows (Visual Studio generator): `.\build\Debug\linkedlist_tictactoe.exe` (or check the configuration folder generated by CMake)

The build directory is intentionally separate from the source files.

## GitHub submission

Create a **public** repository on GitHub, for example `cpp-linkedlist-tictactoe`, then upload/push this directory. Do not commit the generated `build/` directory. A typical `.gitignore` is included below.
